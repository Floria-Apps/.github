# Security Policy

Security is important to FloriaApps.

If you discover a security vulnerability in one of our projects, please report it responsibly.

## Reporting a vulnerability

Please do not publicly disclose security vulnerabilities through GitHub issues, discussions, or pull requests.

Instead, use GitHub's private vulnerability reporting feature when it is enabled for the repository.

If private reporting is not available, contact the maintainers through the contact method provided in the affected project's repository.

## Please include

When reporting a vulnerability, provide:

- A description of the vulnerability
- The affected project and version
- Steps to reproduce the issue
- Potential impact
- Relevant logs or proof of concept when appropriate

Please do not include real credentials, personal information, or other sensitive data.

## Response

We will review security reports and, when appropriate, work with the reporter to understand, reproduce, and address the issue.

Security fixes may result in a new release or security advisory depending on the severity and affected project.

## Responsible disclosure

Please allow maintainers reasonable time to investigate and address a vulnerability before publicly disclosing it.

We appreciate responsible security research and reports that help make FloriaApps software safer.
