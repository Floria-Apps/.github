# FloriaApps

**Open-source software, built with simplicity in mind.**

FloriaApps is a software organization focused on building modern, open-source applications and tools.

We believe software should be:

- Simple to use
- Easy to understand
- Open and transparent
- Built with modern technologies
- Designed to be extensible

## Projects

Our projects cover different areas of software development, with a focus on useful tools and applications for everyday use.

### What we build

- Desktop applications
- Web applications
- Developer tools
- Self-hosted software
- Open-source libraries

## Technology

Our projects may use technologies such as:

`TypeScript` · `React` · `Rust` · `Tauri` · `Node.js` · `Docker`

We choose the technology that best fits each project rather than following a single stack.

## Open Source

FloriaApps is committed to open-source development. Our repositories are available for anyone to explore, use, contribute to, and learn from.

Contributions, bug reports, feature requests, and feedback are welcome.
