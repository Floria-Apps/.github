# Support

Need help with a FloriaApps project?

## Documentation

Start by checking the project's README and documentation.

Most repositories contain installation, configuration, usage, and troubleshooting information.

## Questions

For general questions, use GitHub Discussions when they are enabled for the project.

For project-specific questions, open a discussion in the relevant repository.

## Bug reports

If you believe you found a bug, please use the repository's bug report template instead of opening a general support request.

Include as much relevant information as possible so the issue can be reproduced.

## Feature requests

Use the feature request template to suggest new functionality.

## Security issues

Do not use public issues for security vulnerabilities.

See [SECURITY.md](../SECURITY.md) for the security reporting process.
